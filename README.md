# Stitch TOTP

Open-core **service plugin** for [Stitch Manager](https://github.com/StitchWB/Stitch-Manager): a
2FA/TOTP secret store. Keeps RFC-6238 TOTP secrets encrypted at rest, generates and verifies
codes, and exposes the keys to the Stitch client UI as a declarative page.

- **Kind:** `service` (plugin id `stitch-totp`, service `totp`)
- **Runtime:** spawned by the Stitch `ServicePluginHost` as `python -m stitch_totp`, speaks
  JSON-RPC 2.0 (vendored `RpcPluginServer`)
- **Self-contained:** no `stitch_backend` imports; owns its own SQLite store and a stdlib-only
  TOTP implementation (SHA1/SHA256/SHA512, configurable digits/period). Secrets are encrypted
  at rest with a Fernet-compatible scheme whose tokens interoperate with the Stitch core.

## Commands

`list_keys`, `add_key`, `update_key`, `remove_key`, `link_key`, `claim_key`, `share_group`,
`unshare_group`, `import_secrets`, `generate_secret`, `generate_code`, `verify_code`,
`count_owned_keys`.

## Layout

```
plugin.json              manifest (schema v2, declarative UI + i18n + commands)
stitch_totp/
  __main__.py            JSON-RPC entry point (RpcPluginServer)
  storage.py             SQLite secret store (schema + CRUD)
  totp.py                dependency-free RFC-6238 helpers
  crypto.py              Fernet-compatible at-rest encryption
  _vendor/rpc_server.py  vendored RpcPluginServer (regenerated by stitch_plugin_tools; do not edit)
```

## Development

```bash
pip install ruff
ruff check .
```

Integration tests for this plugin live in the private Stitch monorepo (they need the Stitch SDK
and plugin host). This repo's CI runs lint + compile checks; the monorepo runs the full
plugin-vs-core integration suite against the mirrored copy.

## Distribution

This plugin is **signed and distributed via the Stitch gated server** — the signing key lives in
the private hub, never in this repo. Released packages are assembled from this source, signed in
the hub, and published to the distribution server for entitled users.

## Contributing

External contributions are welcome — open a PR against this repo. Keep changes within the plugin
(no new `stitch_backend` imports, keep the package self-contained). The vendored
`_vendor/rpc_server.py` is regenerated from the core SDK — do not edit it by hand.
